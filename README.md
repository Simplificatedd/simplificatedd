# Hey, I'm Raven

Games got me into computers, and as a kid I wanted to be an inventor. So I did Electronics and Computer Engineering at Ngee Ann Poly. Then I realised hardware means manufacturing costs, procurement and thin margins, so I moved to software. Now I'm doing ICT at SUSS. I interned at Deloitte and spent a semester on exchange at NUS. I also co-founded the school's ICT Interest Group.

Most of what I build starts with something annoying in my own life. If it fixes my problem, it'll probably fix someone else's.

## Things I've built

**[SUSSPlanner](https://sussplanner.com)** · [repo](https://github.com/lester-td/SUSSplanner) `React · TypeScript · Tailwind`<br>
Planning SUSS modules used to mean opening a dozen PDFs, each hundreds of pages of class codes and timings, just to check whether two classes clash and whether one counts towards your minor. I'd wanted to fix this since 2025, but it felt like too much for one person. Then a schoolmate, [@lester-td](https://github.com/lester-td), was keen too, and we built it together in May 2026. We're now working with the school on a read-only API so course data updates on its own.

**[Job Application Tracker](https://github.com/Simplificatedd/JobApplicationTracker)** `React · TypeScript`<br>
A private, self-hosted job tracker. Fork it, deploy it on your own server, and keep your applications to yourself. Works for me, might work for you.

**Home server** `Ubuntu Server · Docker · ZFS`<br>
Runs Plex, Open WebUI, Ollama and a few other services in Docker. It doubles as a NAS with five 4TB drives in RAIDZ1, so 16TB usable with parity, and I can reach it from outside through a tunnel.

**Wi-Fi signal mapper** `ESP32`<br>
An ESP32 I carry around the house that shows every nearby Wi-Fi network and how strong its signal is. Built it to find the dead spots.
